# AutoLazy

Less clicking. Less chat spam. A cleaner minimap.

For **World of Warcraft 1.12.1** with [ClassicAPI 1.15.15+](https://github.com/brues-code/ClassicAPI).

- **Hide loot roll spam.** Keep the winner, item loot and money messages.
- **Auto-roll farm items.** Choose Need, Greed, Pass or Manual in Black Morass, ZG, AQ20 and Naxxramas. Gear rolls stay manual.
- **Clean up your minimap.** Keep addon buttons in one tray. Hide Pirate Radio and Group Finder if you want.
- **Turn in quests with Shift.** Hold Shift when talking to an NPC. Accept new quests and choose multiple rewards yourself.

## Install

[Download ZIP](https://github.com/Fostercare5988/AutoLazy/archive/refs/heads/main.zip), extract it, rename the folder to **AutoLazy**, and put it in `Interface/AddOns/`.

## Use

Type **`/al`** to open settings.

The floating AutoLazy button: **left-click** for the addon tray, **right-click** for settings, or **drag** to move it.

Reload the UI after updating the addon. Restart the game after installing or updating ClassicAPI.
